# Security reporting and sensitive data

The operator must add a real private security contact before public launch. Until then, do not post secrets, member data, exploit payloads containing personal information, or private transaction attribution in a public issue. General non-sensitive bug reports can be tracked with a minimal reproduction.

Never commit production environment files, Privy secrets, wallet keys, newsletter exports, private contacts, licensed font binaries or private infrastructure guides. Server logs intentionally omit exception payloads that could contain secrets.

Production live checkout remains disabled. The 0G Pay adapter is incomplete. Do not bypass it by activating memberships from client callbacks. See docs/INTEGRATIONS.md and docs/LAUNCH-CHECKLIST.md.
